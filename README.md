# makegame

WASD로 이동하고 스페이스바로 공격하는 2D 액션 게임입니다. pygame으로 만들었습니다.

## 실행 방법

```bash
pip install -r requirements.txt
python main.py
```

## 조작법

- **W / A / S / D**: 이동
- **Space**: 전방 180도 부채꼴 범위 공격
- 스토리 화면에서 **Space / Enter**: 다음 대사로 진행
- 게임 오버 / 엔딩 화면에서 버튼 클릭: 재시작

## 게임 구성

- 플레이어는 방어력이 높아 몬스터의 공격을 덜 받습니다.
- 동료(보호 대상) 캐릭터가 플레이어를 따라다니며, 주기적으로 자동 회복합니다. 플레이어와 동료 둘 중 하나라도 체력이 0이 되면 게임 오버입니다.
- 각 스테이지는 몬스터 웨이브 3번으로 구성되며, 특정 스테이지(4, 5)의 마지막 웨이브에는 보스가 등장합니다.
- 모든 스테이지를 클리어하면 엔딩 화면을 보여줍니다.

## 코드 구조

| 파일 | 역할 |
| --- | --- |
| `main.py` | 게임 진입점. 게임 루프와 상태(PLAYING / STORY / GAME_OVER / ENDING) 전환 |
| `config.py` | 화면 크기, 체력, 데미지 등 전체 설정값 |
| `player.py` | 플레이어 이동, 공격, 피격 처리 |
| `monster.py` | 몬스터/보스 스폰, 이동, 그리기 |
| `companion.py` | 동료(보호 대상) 캐릭터의 추격, 자가 회복, 피격 처리 |
| `camera.py` | 카메라 위치 계산과 배경 스크롤 |
| `story.py` | 스테이지 클리어 후 대화 장면 |
| `ui.py` | HUD, 체력바, 버튼 등 화면 표시 요소 |

## 테스트

화면 렌더링 없이 검증 가능한 핵심 로직(카메라 계산, 스토리 진행, 몬스터 스탯)에 대한 단위 테스트가 `tests/` 폴더에 있습니다.

```bash
python -m unittest discover tests
```
